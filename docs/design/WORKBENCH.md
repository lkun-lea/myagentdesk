# 工作台与项目导航

实施对应 [#4](https://github.com/lkun-lea/myagentdesk/issues/4)。登录后默认进入工作台，左侧保留聊天、项目、日程、事项和工作台入口。首页显示常用工具与分类目录。打开项目默认显示时间线，当前版本读取真实的项目创建事件，需求交接及版本计划分别由 #6 和 #16 接入。项目页签用明确的状态标记待接入模块。成员页继续使用 #3 的邀请和授权服务。

## 工具目录

`server/workbench-tools.json` 每条登记包含稳定标识、名称、图标、分类、适用范围、页面入口、版本和启用状态。已有页面入口可通过追加一条登记接入。停用后卡片标明状态并禁用打开，原收藏可取消。回退登记和模块版本时沿用同一标识，刷新后读取当前登记。新增能力的业务页面由对应功能维护。

收藏按已核验账号存入 PostgreSQL。从项目页签直接打开当前项目的工具。工作台中只有一个授权项目时可直接打开，有多个授权项目时显示选择器。工具目录、收藏操作和页面访问使用实时成员关系。旧深链接再次请求项目或时间线时重新鉴权。切换账号清除当前项目与客户端视图，收藏重新从服务端读取。

## 日程与事项

日程支持日、周、月视图和创建、修改、删除。已有事项的「安排时间」进入日程表单，保存后的日程可打开原事项。事项及日程以账号为范围，关联时校验双方归属。客户端按浏览器时区显示，服务端用 [固定版本的 tebb 时间解析模块](FOUNDATION.md) 校验带时区的时间，并按时间范围查询个人日程。

验收使用隔离 PostgreSQL 和邮箱协议替身。至少准备两个授权项目、一个无权项目和两个账号，验证授权列表、工具选择、收藏持久化、切换账号、撤权后的深链接、键盘和窄窗口。日程路径从已有事项安排时间，穿过实际日程 API 的解析、保存和查询，再打开原事项。tebb 客户端的既有日程数据仍由 tebb 持有，项目里程碑由版本计划维护。
